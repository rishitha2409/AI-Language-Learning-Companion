# AI Language Learning Companion – LanguageBuddy

## About the Project
LanguageBuddy is a beginner-friendly website that helps users practise English through grammar checking, vocabulary learning, quizzes, pronunciation, and a 14-day learning plan.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LanguageTool API
- Browser Speech Synthesis API
- Browser Local Storage

## Main Features
1. 14-day English learning plan
2. English grammar checker
3. English–Tamil vocabulary
4. Beginner-level English quiz
5. Audio pronunciation practice
6. Progress tracking
7. External AI learning tool links

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open `index.html` using a browser or Live Server.
3. Navigate through the website sections.
4. Use an internet connection for online grammar checking.

## Project Files
- index.html – Website structure
- style.css – Website design
- script.js – Interactive features
- README.txt – Project documentation

## Limitations
- Grammar checking requires an internet connection.
- Pronunciation depends on browser support.
- Progress is stored locally in the browser.
- External AI tools are accessed through links.
